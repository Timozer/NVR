# Privacy Policy / 隐私政策

## 中文版

### 一、 100% 本地化闭环
您的隐私安全对我们至关重要。NVR 采用 100% 本地化闭环架构。我们向您郑重承诺：本软件未设立任何第三方云端服务器，绝对不收集、不缓存、不上传您的任何流媒体视频流、监控声音、录像文件或个人信息。所有数据流均在您的本地网络内直接与摄像头交互并本地存储。

### 二、 凭证安全
您在添加摄像头时输入的账号、密码或 IP 地址等敏感凭证，均直接存储在您的 iOS 本地沙盒或 Apple 系统 Keychain 中。这些数据仅用于本地连接鉴权，外界无任何途径获取。

### 三、 系统权限调用
为了提供正常的功能，本软件需要调用以下系统权限：
1. 【局域网/本地网络】：用于发现和连接您相同 Wi-Fi 下的摄像头设备。
2. 【照片库权限】：当您保存截图或视频至系统相册时需要此权限。
3. 【文件共享】：本软件支持通过系统“文件”App访问您本地保存的录像。

### 四、 无第三方 SDK
本软件未集成任何广告追踪、行为数据统计分析等侵害隐私的第三方商业化 SDK，确保软件运行绝对纯净安全。

## English Version

### 1. 100% Localized Closed Loop
Your privacy and security are paramount to us. NVR adopts a 100% localized closed-loop architecture. We solemnly promise: This software has no third-party cloud servers, and absolutely does not collect, cache, or upload any of your streaming video streams, monitoring sounds, recording files, or personal information. All data streams interact directly with cameras within your local network and are stored locally.

### 2. Credential Security
Sensitive credentials such as accounts, passwords, or IP addresses entered by you are directly stored in your iOS local sandbox or Apple system Keychain. This data is only used for local connection authentication.

### 3. System Permission Calling
To provide normal functions, this software needs to call the following system permissions:
1. [Local Network]: Used to discover and connect camera devices under the same Wi-Fi.
2. [Photo Library]: Required when you save screenshots or videos to the system album.
3. [File Sharing]: This software supports accessing your locally saved recordings through the system 'Files' app.

### 4. No Third-party SDK
This software does not integrate any third-party commercial SDKs such as advertising tracking and behavioral data statistics, ensuring that the software runs absolutely pure and safe.
